## Implemented path

`collectAssignmentPage()` uses the existing course discovery flow until courses close, then chooses a retained assignment resource from the private journal ledger. One explicit call reads at most one provider page; subsequent calls recover a captured request, renew a lease, close a terminal assignment resource, or finish the scan. Other required kinds remain open and prevent a false full finish. No scheduler or installed host is added.

The existing bounded reader now validates assignment pagination for exactly one course and the same configured Canvas origin, `per_page=50` and `override_assignment_dates=true`, with only an opaque `page` parameter. This follows [Canvas's documented requesting-user date override option](https://developerdocs.instructure.com/services/canvas/resources/assignments). Response identity, duplicate IDs, redirects, JSON type/UTF8, body/Link/cursor bounds and cycles are checked. A selected course must still be in current authorized context before reading. No caller supplies a normal collection course ID.

The client sends only assignment IDs and eligible descriptions to private `/academic/extract`. The adapter authenticates the ingestion bearer through the existing Store context and checks connection, generation, revision, selected course and assignment kind before and after conversion. It reuses the unchanged #88 HTML parser, with 50 items/1MiB aggregate UTF8 input,2MiB route wrapper and 24000 output characters per item. The parser performs no fetching/execution or raw-source persistence. Raw HTML stays out of the upload journal and public status. Locked descriptions are omitted; no permission flag is guessed.

Every extraction response must bind the same course and exact fetched assignment IDs. Missing/duplicate/foreign rows, invalid strings or false-complete claims reject before journaling. Account/context/credential fences run after provider reading and before extraction, again after conversion, and through existing commit/delivery checks. The whole tick retains the existing per-storage lock; concurrent operations reject honestly. Known 100-page/5000-item and global sequence limits block before another provider read; the regression first reproduced two unnecessary reads, then passed after preflight was added.

The existing mapper retains rubric, submission type, effective date and metadata gaps. Existing HTML extraction is always partial and preserves linked/hidden/nontext/malformed/size limitations. No clipping or complete-HTML claim is introduced. The mapped C2 payload is persisted before upload. A pending receipt recovers before any provider refetch; worker recreation preserves the existing request/key/body. Unmapped provider constraints remain explicit missing evidence. Empty terminal lists can prove empty enumeration; nonempty HTML pages cannot falsely close complete.
